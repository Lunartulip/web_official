AI 时代的投资经理，可以把越来越多的信息收集、模型计算和研究执行交给系统，自己的职责逐步集中到目标定义、边界设计、风险治理和系统训练。

这条变化正在打开一种新的资管组织形态：基金经理负责设计投资宪法、分配决策权、设置风险预算和升级条件；专业 Agent 持续观察市场、更新假设、运行模型、保留证据；组合与 NAV 负责给整套过程提供统一反馈。

这套结构的目标，是让投资认知获得持续运行、持续验证和持续学习的能力。

## 一张 Self-Driving Portfolio 的施工图

2026 年 4 月，Andrew Ang、Nazym Azimbayev 和 Andrey Kim 发布了工作论文 [The Self Driving Portfolio: Agentic Architecture for Institutional Asset Management](https://arxiv.org/abs/2604.02279)。

论文把机构战略资产配置拆解成约五十个专业 Agent：

- 宏观 Agent 识别经济与市场状态；
- 各资产类别 Agent 生成资本市场假设；
- 二十多种组合构建方法并行运行；
- 专业 Agent 相互审阅、批评和投票；
- CIO Agent 汇总不同方案；
- Researcher Agent 搜索系统尚未覆盖的方法；
- Meta-Agent 比较历史预测与真实结果，并提出 Prompt、Skill 和代码的更新建议。

每个 Agent 都拥有明确的岗位说明、工具权限、Python 脚本和结构化输出。语言模型承担材料阅读、证据比较与判断表达，计算和优化由确定性脚本完成。研究过程同时留下机器可读的 JSON、可供人检查的报告与完整运行 Trace。

这套架构把投委会里的多角色协作写成了可以重复执行的协议。Agent 的数量提供分工密度，角色之间的审阅机制提供观点挑战，Meta-Agent 提供跨周期学习能力。

## Investment Policy Statement 成为可执行的投资宪法

整套系统受到 Investment Policy Statement（IPS）的约束。

传统资管组织使用 IPS 定义投资目标、可投资范围、风险预算、流动性要求和治理责任。在 Agentic 架构中，这些条款进一步成为机器可以读取和执行的约束：

- 哪些资产进入 Coverage；
- 各类风险暴露的上下限；
- 哪些工具和数据源可以调用；
- 哪些动作可以自动完成；
- 哪些判断需要升级给基金经理；
- 哪些异常会触发风险收缩；
- 哪些规则变更需要投委会审批；
- 每一次执行需要保存哪些证据。

基金经理的责任因此进入系统设计层。投资目标、风险偏好和人类否决权都需要显式表达。系统的自主程度越高，权限、审计、版本管理和升级机制越需要清晰。

当多个 Agent 使用同一个基础模型时，它们可能共享相似的知识边界与推理盲区。异质模型、确定性检查、独立数据源、人类复核和 adversarial review 共同构成治理结构。每一次关键结论都需要回到证据，每一次高影响动作都需要经过对应权限。

## 回测数字提供了什么信息

论文给出的 1996—2026 年历史回测中，Agentic 组合的 Sharpe ratio 为 0.39，60/40 基准为 0.41；最大回撤分别为 -25.6% 和 -34.3%。

这些数字展示了组合在收益波动比、资产分散与回撤路径上的具体特征。0.39 的 Sharpe ratio 没有构成稳定 Alpha 的证据。较低的最大回撤说明这套组合构建过程形成了不同的风险暴露。

论文同时讨论了大模型回测中的 look-ahead bias。今天的模型在训练阶段已经读取大量历史金融信息，历史时点上的“决策”可能携带未来知识。严格 point-in-time 数据只能解决信息集的一部分问题，模型参数中保存的历史知识仍然难以完全隔离。

前瞻运行因此承担关键验证职责。系统需要在真实时间中记录当时可见的信息、当时形成的判断、后续采取的动作和市场最终给出的结果。连续样本逐步增长以后，研究者才能识别：

- 哪些假设类型具有稳定解释力；
- 哪些模型在特定 Market Regime 下更可靠；
- 哪些信息提高了决策质量；
- 哪些错误来自事实、映射、时机、标的或仓位；
- 哪些人类干预创造了价值；
- 哪些自动化规则需要收缩或重写。

## 报告完成之后，投资过程继续运行

AI 已经可以阅读公告与研报、整理财务数据、跟踪新闻、比较公司、提取产业链关系并生成结构完整的分析。

主动投资随后进入一条持续数周、数月甚至数年的决策链：

**Coverage → Evidence → Hypothesis → Decision → Position → NAV → Decision Memory**

Coverage 定义系统长期观察的市场、产业链与资产范围。

Evidence 记录现实世界发生的变化，并保留来源、时间戳与证据强度。

Hypothesis 把分散信息组织成可以验证、强化、削弱和失效的投资命题。

Decision 综合情景概率、赔率、估值、市场状态、组合约束与风险预算。

Position 把判断转换为资本暴露，并记录建仓、调整、退出与人类覆盖动作。

NAV 汇总市场对整套过程的连续反馈。

Decision Memory 保存当时的信息集、规则版本、执行路径、结果归因与后续修正。

这条链路需要一个贯穿全程的共同主键。一次产业判断、一次组合动作和一次净值变化需要能够彼此关联。基金经理可以沿着记录回到判断形成的现场，系统也可以使用同一批前瞻数据训练下一轮规则。

## Research Desk：持续运行的买方研究状态

LunarTulip 正在构建的 Always-On Research Desk，承担这条链路中的持续研究层。

事件账本记录影响判断的变化，并把事件连接到对应假设与产业因果路径。

假设看板维护每个观点的生命周期，包括建立时间、证据变化、反证条件、验证窗口和当前状态。

每日研究简报压缩当日的重要变化，说明哪些判断被更新、哪些节点需要继续验证、哪些风险进入观察范围。

Decision Memory 保存判断形成时的信息集、后续动作、结果反馈和归因记录。

AlphaMap 负责产业链驱动、传导、瓶颈与价值兑现路径。QuantLab 负责因子、信号、情景和组合层验证。Research Desk 把这些模块连接到同一个时间连续体中。

当前的机构合作以受邀试点和持续共研展开。双方从一个真实研究命题出发，共同确认 Coverage、数据边界、输出节奏和人类复核节点。系统在受控范围内运行，团队观察它如何处理变化、维护假设与积累决策记忆。

## AI-native Fund 的长期组织形态

LunarTulip 的长期愿景指向 AI-native Fund。

这家资管组织会围绕一套持续运行的投资系统建立。人的投资责任与最终判断处于核心位置，Agent 提供高密度覆盖、证据追踪、模型计算和流程执行，Investment Constitution 规定目标、权限、风险与升级条件。

在研究层，系统持续覆盖全球泛 AI 科技产业链，连接 A 股、美股与港股的技术演进、供应链变化、利润传导和资产定价。

在决策层，基金经理定义组合目标、风险预算、持仓边界和人类否决权。系统为每个动作保留对应假设、证据、赔率和情景条件。

在执行层，权限系统区分研究建议、模拟动作、真实交易和高影响变更。风险闸门检查流动性、集中度、回撤、市场状态和规则冲突。

在学习层，NAV、Decision Memory 与归因系统共同工作。每一次判断都进入前瞻样本，每一次规则更新都保留版本，每一次人类覆盖都留下原因和结果。

日常运行可以由 Research Desk 持续完成市场观察和状态更新。基金经理负责关键命题、组合责任和异常处置。投委会定期审阅系统行为、风险边界、模型漂移与前瞻表现。工程与研究团队根据审阅结果更新 Agent、Skill、数据和治理规则。

未来的资管业务会在匹配的主体、资质和合规框架中展开。长期建设目标保持明确：让产业理解、量化纪律、Agent 工作流、组合管理与净值反馈进入同一套可持续演化的买方基础设施。

## 投资经理开始训练一套持续接受市场奖惩的系统

Self-Driving Portfolio 展示了一张早期施工图。它把 Agent 分工、组合方法、IPS 治理、同行评审和 Meta-Agent 学习放进同一个组织模型。

这张施工图还会经历大量前瞻验证。模型相关性、数据污染、规则漂移、权限治理、人类监督疲劳与市场状态变化，都需要在长期运行中积累答案。

投资经理的工作内容正在扩展。他需要理解市场，也需要设计系统；需要形成判断，也需要定义判断如何被验证；需要管理组合，也需要训练组织如何从结果中学习。

当 Coverage、Evidence、Hypothesis、Decision、Position、NAV 与 Decision Memory 连成一条完整链路，投资认知就拥有了持续生命。判断会留下时间戳，动作会留下责任链，结果会进入下一轮规则。

AI-native Fund 将沿着这条路径生长：一套由人承担责任、由 AI 扩展能力、由市场持续结算、由记忆推动进化的主动投资系统。
